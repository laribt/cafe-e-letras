
# Café & Letras

Projeto acadêmico desenvolvido na disciplina de Projeto de Software.

## Objetivo

Desenvolver um sistema para auxiliar uma cafeteria comunitária
na organização do acervo de livros e no controle de empréstimos
e devoluções.

## Problema identificado

O controle manual de livros e empréstimos pode provocar
informações inconsistentes, dificuldade para localizar
exemplares e atrasos nas devoluções.

## Funcionalidades do MVP

- Consulta de livros e disponibilidade.
- Cadastro de livros.
- Cadastro de leitores.
- Registro de empréstimos.
- Registro de devoluções.
- Visualização dos resultados das operações.

## Tecnologias

Protótipo:
- HTML5
- CSS3
- JavaScript

Implementação planejada:
- Python 3.12
- Django 5.2
- PostgreSQL
- Bootstrap 5.3

## Telas do protótipo

1. Menu inicial: index.html
2. Registro de empréstimos: emprestimos.html
3. Resultado do empréstimo: resultado.html

## Como executar o protótipo

1. Baixe ou clone este repositório.
2. Abra a pasta no VS Code.
3. Abra o arquivo index.html no navegador.
4. Acesse a opção Empréstimos para testar o fluxo.

## Situação do projeto

Protótipo inicial desenvolvido.

As operações em JavaScript são simulações.
A implementação com Django e banco de dados será
realizada nas próximas etapas.

## ODS relacionado

ODS 4 — Educação de Qualidade.
